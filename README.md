- Achieved 500+ successful test translations with under 1-second latency

**Technologies**: Python, Flask, JavaScript, DeepL API
**Repository**: https://github.com/Paul-Emmanuel-Buffe/lingua-franca

Comprehensive data analysis case study for European indoor climbing gym chain.

- Performed customer segmentation and behavior analysis
